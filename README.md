# ⏱️ Fullstack Time Tracker (React + Node.js)

Веб-приложение для точного учета рабочего времени, контроля задач и визуального анализа эффективности работы над IT-проектами.

🚀 **[Посмотреть приложение в деплое](https://time-tracker-client-8ayj.onrender.com)**

---

## 🛠️ Технологический стек

### Frontend:
* **React 19** (Функциональные компоненты, Hooks: `useRef`, `useState`, `useEffect`)
* **TypeScript** (Статическая типизация для надежной кодовой базы)
* **Redux + Redux Thunk** (Управление глобальным состоянием приложения)
* **React Router** (Маршрутизация и навигация между страницами)
* **Recharts** (Интерактивная визуализация данных и графики аналитики)
* **Tailwind CSS** (Адаптивная верстка с полной поддержкой мобильных устройств)
* **React Hook Form + Yup** (Валидация форм)
* **React Easy Crop** (Редактирование и обрезка аватара пользователя)

### Backend:
* **Node.js & Express** (REST API, архитектура MVC)
* **MongoDB & Mongoose** (Проектирование схем и моделей базы данных)
* **Bcrypt** (Надежное хеширование паролей пользователей)
* **JWT (JSON Web Tokens)** (Безопасная аутентификация и сессии)
* **Validator.js** (Валидация входных данных)
* **Cookie Parser** (Обработка cookies для сессий)

## 🔑 Ключевые фичи и архитектурные решения

* **Производительный таймер:** Точное время старта и финиша сессии трекается через `new Date()`. Визуальный счетчик реализован через `setInterval` с использованием мутабельного хука `useRef` для оптимизации ререндеров.
* **Безопасность и авторизация:** Полноценная регистрация/авторизация пользователей. Пароли хешируются через `bcrypt`. Приватные маршруты защищены кастомными `middleware`, проверяющими валидность JWT токена.
* **Полный CRUD-цикл:** Управление Проектами, Задачами, временными записями и комментариями.
* **Система статусов задач:** `todo`, `in-progress`, `completed` — наглядный трекинг прогресса.
* **Приоритеты задач:** `low`, `medium`, `high` — гибкое планирование работы.
* **Архивация:** Возможность архивировать проекты и задачи для очистки рабочего пространства.
* **Интерактивная аналитика:** Графики на базе `Recharts` визуализируют временные затраты по проектам.
* **Личный кабинет:** Редактирование профиля, загрузка и обрезка аватара, настройка timezone, безопасный `logout`.
* **Ролевая модель:** Поддержка ролей `ADMIN` и `USER` для расширения функционала.

## 🗄️ Структура моделей Базы Данных (MongoDB)

| Модель | Поля | Описание |
|--------|------|----------|
| **User** | login, password, name, avatar, role, settings.timezone | Данные пользователя и настройки профиля |
| **Project** | owner, title, description, isArchived | Глобальные проекты с возможностью архивации |
| **Task** | owner, projectId, title, description, status, priority, isArchived | Задачи с привязкой к проектам, статусами и приоритетами |
| **TimeEntry** | owner, taskId, startTime, endTime, duration, comment | Временные промежутки с комментариями |

## ⚙️ Локальный запуск проекта

Для запуска проекта на локальном компьютере вам понадобятся установленные **Node.js** и **MongoDB**.

### 1. Склонируйте репозиторий:
```bash
git clone https://github.com/ururu42/time-tracker-fullstack.git
cd time-tracker-fullstack
```

### 2. Настройте переменные окружения:

**Backend** (`backend/.env`):
```env
DB_CONNECTION_STRING="mongodb+srv://<USERNAME>:<PASSWORD>@<HOST_NAME>"
JWT_SECRET="<SECRET>"
PORT=3001
```

**Frontend** (`frontend/.env`):
```env
VITE_API_URL=http://localhost:3001/api
```

### 3. Установите зависимости и запустите бэкенд:
```bash
cd backend
npm install
npm start
```

### 4. Установите зависимости и запустите фронтенд:
```bash
cd ../frontend
npm install
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5173`
